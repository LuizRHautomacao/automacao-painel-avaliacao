# Automação de Painel e Alertas para Avaliação de Desempenho

Projeto em Python desenvolvido para otimizar o processo de avaliação de desempenho, reduzindo trabalho manual, aumentando a padronização das rotinas e ampliando a visibilidade gerencial do andamento das avaliações.

## Objetivo

Automatizar etapas importantes do processo avaliativo, com foco em:

- geração de alertas e comunicações de apoio;
- apoio à auditoria de líderes;
- consolidação de informações em painel gerencial;
- redução de esforço operacional no RH.

## O que a solução entrega

A automação foi construída para apoiar uma rotina real de RH, trazendo mais agilidade, controle e rastreabilidade ao processo.

Principais entregas do projeto:

- processamento automatizado de dados do ciclo avaliativo;
- geração de alertas para acompanhamento de pendências;
- apoio à auditoria de lideranças;
- organização das informações em painel para acompanhamento gerencial.

## Estrutura atual do repositório

- `gerar_alertas.py` → script principal da automação;
- `executar_alertas.bat` → arquivo de execução prática do projeto.

## Benefícios do projeto

- redução de atividades manuais e repetitivas;
- maior controle sobre o andamento das avaliações;
- apoio à gestão de pendências;
- melhor acompanhamento por liderança;
- base para evolução futura do painel em soluções mais visuais e dinâmicas.

## Observação

Para preservar confidencialidade e segurança das informações, arquivos com dados reais, bases internas e saídas contendo informações sensíveis não foram publicados neste repositório.

## Evolução futura

Entre as próximas evoluções previstas para o projeto estão:

- publicação de exemplos anonimizados;
- inclusão de evidências visuais do fluxo;
- documentação complementar do processo;
- possível evolução do painel para uma camada visual mais avançada.
